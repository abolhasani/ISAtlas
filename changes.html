Release history

What changed in each Atlas version.

The version is visible throughout the site and will be updated with every released change.

v0.2.4July 25, 2026

Time controls and journal snapshots

  • Added a synchronized publication-year slider pair above the existing year fields.
  • Added live journal snapshots with matching paper count, cumulative citations, and year coverage for every selected journal.
v0.2.3July 25, 2026

Stable focused networks

  • Removed the stale empty-state message from focused views.
  • Stabilized citation curves so they terminate at node edges instead of changing shape while nodes settle.
  • Clicking a connected paper updates the information panel without rebuilding the focused neighborhood.
  • Focused nodes now show the first three title words as a concise label.
v0.2.2July 25, 2026

Visible focus neighborhoods

  • Replaced the blocking paper modal with a modeless, scrollable side panel.
  • The cited-and-citing graph now remains visible and interactive while paper metadata is open.
v0.2.1July 25, 2026

Graph interaction repair

  • Corrected stretched journal checkboxes so the selection panel aligns cleanly.
  • Removed the hidden loading overlay from the layout and pointer layer once data is ready, restoring clear empty-state text and node clicks.
v0.2.0July 25, 2026

Local data, speed, and control

  • Added compact browser data bundles so opening the site locally no longer depends on blocked JSON fetches.
  • Reduced initial graph data to focal papers; external neighbor metadata loads only after selecting a paper.
  • Defaulted the graph to year 2026 with no journals selected, added curved citation edges, and retained zoom-aware dragging.
  • Made network controls persist while scrolling and refined the footer into a smaller, bottom-aligned status line.
  • Expanded search filters for SDG, language, work type, open access, and abstract availability, with result sorting.
v0.1.1July 25, 2026

Navigation and freshness

  • Added scroll-wheel zoom, zoom controls, zoom reset, and zoom-aware dragging to the graph.
  • Added the latest database-update timestamp beside the maintainer footer on every page.
v0.1.0July 25, 2026

Atlas foundation

  • Interactive canvas citation graph for MISQ, ISR, and JMIS.
  • Journal, time, topic, and subfield controls.
  • Focused paper neighborhoods, metadata panels, smooth drag physics, and directed citation arrows.
  • Search and extract workspace with JSON and Excel-compatible downloads.
  • Lavender daylight theme, solid-black night mode, local theme preference, data-readiness indicators, and shared footer.
